# Hospital Management System

A comprehensive web-based Hospital Management System developed with **Django** and **MySQL** to automate and streamline hospital operations.

## Features

- User Authentication & Role Management
- Patient Registration & Medical Records
- Doctor Management
- Appointment Scheduling
- Consultation Management
- Pharmacy Management
- Laboratory Management
- Inventory & Stock Management
- Billing & Payments
- Reports & Analytics
- Responsive Dashboard

## Technologies

- Python 3
- Django
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Git & GitHub
